DEVELOPER REFERENCEAPI v1

Build on the TWI contracts

Use the documented HTTP API with a Platform-issued access token whose audience is the configured TWI API. These examples describe existing contracts; they do not create credentials or prove that a deployment is configured.

Security boundary

Never paste access tokens into this page, commit them to source control, or place them in URLs. Obtain tokens through the configured Platform identity flow or an approved trusted runtime. Tenant, subject, scopes, acquisition policy and idempotency are enforced by TWI.

Supported endpoints

  • POST /v1/jobs — create search, fetch, or browser jobs; requires Idempotency-Key and matching twi:search, twi:fetch, or twi:browser scope.
  • GET /v1/jobs/{job_id} — inspect a tenant-scoped job with twi:jobs:read.
  • POST /v1/jobs/{job_id}/cancel — request cooperative cancellation with twi:jobs:cancel.
  • GET /v1/jobs/{job_id}/evidence — export a successful in-scope fetch job with twi:evidence:export.
  • POST /v1/research/verify — compare bounded citations against captured text with twi:research:verify.
  • /v1/monitors — create/read monitors and explicitly enqueue, inspect, pause, resume, or delete using documented monitor scopes.

Create a search job

curl --fail-with-body --request POST "$TWI_API_BASE_URL/v1/jobs" \
  --header "Authorization: Bearer $TWI_ACCESS_TOKEN" \
  --header "Content-Type: application/json" \
  --header "Idempotency-Key: $TWI_IDEMPOTENCY_KEY" \
  --data '{"kind":"search","payload":{"query":"primary sources for a published claim","limit":5}}'

Set variables in your trusted runtime. Use a fresh idempotency key for a new logical operation; reuse it only when retrying that same request.

Verify captured citations

curl --fail-with-body --request POST "$TWI_API_BASE_URL/v1/research/verify" \
  --header "Authorization: Bearer $TWI_ACCESS_TOKEN" \
  --header "Content-Type: application/json" \
  --data '{"claims":[{"claim_id":"claim-1","statement":"The source makes this statement.","citations":[{"job_id":"REPLACE_WITH_CAPTURED_JOB_ID","quote":"REPLACE_WITH_AN_EXACT_QUOTE_FROM_CAPTURED_TEXT"}]}]}'

Verification reports quote matching against captured text. It does not assess factual truth or source authority. Replace template values with a real, accessible captured job.

Examples are templates. No request is sent from this reference panel.

Canonical details: docs/api/jobs-v1.md, docs/api/evidence-packages-v1.md, and docs/api/monitors-v1.md. Browser access requires a configured same-origin reverse proxy or explicitly approved HTTPS API origin.
