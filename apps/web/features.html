CAPABILITIES

Research you can inspect.

Tinlyt is designed to make web investigation reviewable: preserve the source, understand the retrieval, and keep the limits of each finding visible.

01 / DISCOVER

Search and retrieve

Bring web sources into a consistent investigation workflow. Retrieval results should retain the URL and available metadata needed to inspect where material came from.

02 / TRACE

Inspect runs

Review supported execution states, errors and available job details. A result should not conceal whether work failed, was cancelled or is still running.

03 / PRESERVE

Keep provenance

Retain source references and integrity metadata where supported. Evidence exports should be inspectable and checked for integrity before downstream use.

04 / COMPARE

Review claims and citations

Compare a statement with the cited passage and make the match or mismatch visible. Text similarity is not independent proof that a statement is true.

05 / OPERATE

Monitor change

Monitoring workflows are subject to the supported backend, scheduling authority and alert configuration. This page does not imply that live alerts are enabled.

06 / INTEGRATE

Use governed interfaces

API and agent integrations must follow the authoritative Tinlance Platform identity, authorization, policy and audit boundaries. Availability depends on deployment configuration.

Honest by design

Product interfaces distinguish illustrative examples from live results. No sample metrics, captures, customers or verification verdicts should be mistaken for operational evidence.
