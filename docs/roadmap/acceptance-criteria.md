# Acceptance criteria

Each workstream must attach evidence for:

- scope and ownership boundary;
- implementation and code review;
- unit, contract, integration, security, and relevant end-to-end tests;
- CI workflow run and commit SHA;
- threat-model and operational-document updates;
- consumer compatibility and TSIC conformance where applicable;
- unresolved risks and explicit non-goals.

A check that has not run is not passing. A workflow configuration is not proof that a workflow passed.
