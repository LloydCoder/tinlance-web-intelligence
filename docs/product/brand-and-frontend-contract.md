# Tinlyt Brand and Frontend Contract

## Approved draft identity
Use the supplied `tinlyt-logo-kit` assets as the sole logo source. Draft palette: Ink `#0B1220`, Paper `#F2F5FA`, Signal `#2DD4BF`, Signal deep `#0D9488`, Muted `#8996AA`. The logo-kit README states that the name and mark are not trademark-cleared. Do not use ® or ™ and do not remove `noindex` until clearance and launch approval are recorded.

## Product language
Use “source captured”, “quote matched”, “execution trace” and “claim/citation comparison” only where supported. Retrieval does not prove truth; quote matching does not prove a claim. Label synthetic workflow cards “Illustrative example” and use neutral example domains for mock traces.

## UX and accessibility
Core marketing copy must be in HTML without JavaScript. Body text contrast target is at least 4.5:1; all controls need visible keyboard focus. Layout must work at 375 px without horizontal overflow. Respect `prefers-reduced-motion`. No analytics/tracking scripts without explicit approval.

## Routes
- `/`: marketing.
- `/app`: existing workspace.
- API paths and authentication callbacks remain unchanged unless a separate reviewed contract change authorizes otherwise.

## Launch policy
Only link to real pages. Pricing, blog, privacy, terms, security and status content must not be implied to exist when it does not. Privacy and Terms require approved content before public launch. Keep noindex until trademark/domain review and owner approval.
